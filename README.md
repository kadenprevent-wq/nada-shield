# nada-shield
Open-source Windows security dashboard built around Microsoft Defender.
Here is how to use Nada Shield v0.2. Once you download the zip file, extract it, and find the folder named "NADA_Shield_v0.2." Once you found the folder, enter it, and enter another NadaShield folder if prompted. Once entered, find the Windows Batch File named BUILD_EXE. Once found, run the file and wait for it to install. Once it installs, press any key to exit out. Close files and re open, go to downloads/NADA_Shield_v0.2/NADA_Shield/dist/NADA_Shield and execute NADA Shield.
